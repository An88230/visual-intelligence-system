# Code to Prompt

## Convert a Visual Code into an AI Image Prompt

This template turns a code into a controlled visual prompt.

It is designed for cinematic advertising, product visuals, editorial campaigns, symbolic posters, and AI visual exploration.

---

## Input

```text
Code Number:
Code Name:
Subject:
Product / Object:
Human State:
Usage:
Aspect Ratio:
Avoid:
```

---

## 1. Extract the Visual Law

```text
This code is not about [surface meaning].
It is about [hidden law].
```

Example:

```text
This code is not about a product.
It is about the version of the self the product permits.
```

---

## 2. Define the Human State

Do not use obvious emotion labels.

Weak:

```text
sad person
happy customer
confident man
```

Strong:

```text
a person carrying an unnamed internal lack
someone standing between hesitation and control
a figure whose reflection appears more resolved than their physical body
```

---

## 3. Define the Product Role

The product is not a hero.

It is a function inside the emotional structure.

```text
Product as permission object
Product as threshold
Product as witness
Product as mirror
Product as evidence
Product as rupture
Product as mask
Product as key
```

---

## 4. Prompt Architecture

```text
A cinematic advertising image of [subject] in a state of [unnamed human state],
where [product/object/environment] behaves as [symbolic role],
revealing [recognition / transformation / tension].
The visual world follows [code law],
with [lighting], [texture], [composition], [camera behavior], and [atmosphere].
The image should feel like [impact], not like [cliché].
```

---

## 5. Visual Control Fields

```text
Subject:
Human State:
Object Role:
Environment:
Lighting:
Camera:
Texture:
Color Logic:
Motion / Stillness:
Symbolic Detail:
Signature Integration:
Negative Prompt:
Aspect Ratio:
```

---

## 6. Negative Prompt

Use this to protect the image from becoming generic.

```text
No smiling influencer, no obvious product placement, no direct sales mood, no exaggerated luxury clichés, no shopping behavior, no fake happiness, no aggressive branding, no busy background, no cartoon look, no plastic skin, no cheap neon cyberpunk, no overexplained symbolism, no motivational poster feeling, no flat watermark, no text-heavy layout.
```

---

## 7. Signature Integration

When needed, integrate the signature as part of the world:

```text
The signature “© 2025 Nabil88 | nabil88.art” appears subtly as fragmented light metadata reflected across the surface, not as a flat watermark.
```

---

## 8. Final Prompt Format

```text
[Full cinematic prompt]

Negative prompt:
[negative prompt]

Aspect ratio:
[ratio]
```

---

## Final Rule

The prompt must not describe a beautiful image.

It must describe a psychological event that became visible.
