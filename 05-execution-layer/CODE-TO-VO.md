# Code to VO

## Convert a Visual Code into Voice-Over

This template turns a visual code into spoken narration.

It is designed for calm authority, philosophical advertising, campaign films, reels, manifestos, and sonic identity.

---

## Input

```text
Code Number:
Code Name:
Project / Brand:
Audience:
Duration:
Dialect / Language:
Tone:
Platform:
```

---

## 1. Extract the Spoken State

Ask:

```text
What is the feeling before it becomes language?
```

Do not start with information.

Start with pressure.

Weak:

```text
We offer a premium product.
```

Strong:

```text
Some things do not make you different.
They let you recognize yourself.
```

---

## 2. Define the Voice Position

```text
The voice is not selling.
The voice is witnessing.
```

Choose one:

```text
Calm authority
Quiet warning
Internal recognition
Desert stillness
Urban fatigue
Soft command
Philosophical restraint
```

---

## 3. VO Structure

```text
Opening: enter through feeling
Turn: reveal the hidden tension
Recognition: name what was unnamed
Product / Brand Role: appear as permission, not interruption
Close: leave a mark, not an instruction
```

---

## 4. Rhythm Rules

```text
Short lines.
Controlled silence.
No begging.
No over-explaining.
No loud motivation.
No commercial shouting.
Each line must carry weight.
```

---

## 5. Sonic Notes

```text
Pace: slow / measured / steady
Voice: calm / dry / close / grounded
Breath: audible but controlled
Silence: used as meaning, not pause filler
Music: minimal / low pulse / restrained texture
```

---

## 6. VO Draft Template

```text
[Opening line]

[Silence]

[Line that reveals the hidden state]

[Line that shifts the meaning]

[Brand / product appears as threshold]

[Final line that stays]
```

---

## 7. Performance Direction

```text
Read as if you are not trying to convince anyone.
Read as if the truth already knows its place.
Let the silence do part of the argument.
```

---

```text

```

---

## Final Rule

A strong VO does not decorate the image.

It gives the image permission to become understood.
