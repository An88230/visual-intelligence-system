# Execution Layer

## The Translation Layer

This layer does not rewrite the codes.

It translates them into usable creative outputs.

```text
Visual Code → Human State → Creative Structure → Campaign / Prompt / VO / Shot
```

The original codes remain untouched.

This folder exists so the system can be used in real projects without flattening its philosophy.

---

## Purpose

The Visual Codes Dictionary stores laws.

The Execution Layer turns those laws into work.

Use it when you need to produce:

- campaign concepts
- visual directions
- AI image prompts
- voice-over scripts
- shot lists
- captions
- presentation logic
- creative briefs

---

## Core Rule

```text
Execution is translation, not decoration.
```

Do not add surface beauty before identifying the inner structure.

Do not begin with platform format.

Do not begin with product features.

Begin with the human state.

---

## Operating Sequence

```text
1. Choose a code.
2. Extract the hidden human state.
3. Define the tension.
4. Choose the output type.
5. Translate the code into structure.
6. Apply the 6 Law filter.
7. Remove anything that does not increase truth.
```

## The Execution Test

Before final output, ask:

```text
Does this output make recognition inevitable?
```

If the answer is no, return to the code.

If the answer is yes, remove one more unnecessary layer.

---

## Final Principle

The system is not designed to produce more.

It is designed to strike cleaner.
