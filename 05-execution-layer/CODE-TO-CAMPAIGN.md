# Code to Campaign

## Convert a Visual Code into a Campaign Structure

Use this template when turning any code from the Visual Codes Dictionary into a real campaign.

The goal is not to explain the code.

The goal is to build a campaign that makes the audience recognize something inside themselves.

---

## Input

```text
Code Number:
Code Name:
Product / Brand / Project:
Audience:
Platform:
Desired Output:
```

---

## 1. Extract the Human State

Ask:

```text
What does the audience feel but not say?
```

Write it as an unnamed state, not as a market segment.

Weak:

```text
People want luxury.
```

Strong:

```text
A person wants permission to feel more complete without admitting they feel incomplete.
```

---

## 2. Define the Inner Tension

```text
The audience is between [current self] and [unspoken desired self].
```

Example:

```text
The audience is between looking successful and feeling internally scattered.
```

---

## 3. Translate the Code into Campaign Law

```text
Because this code says: [core law]
The campaign must: [creative behavior]
```

Example:

```text
Because Code 48 says people buy the version of themselves the product permits them to become,
the campaign must show the product as a threshold, not as an object.
```

## 6. Copy System

### Hook

```text
A line that enters before explanation.
```

### Body

```text
A short structure that reveals the tension.
```

### Closing Line

```text
A sentence that leaves the viewer with recognition, not instruction.
```

---

## 7. Shot List

```text
Shot 01 — State before recognition
Shot 02 — Object / environment as threshold
Shot 03 — detail that carries the code
Shot 04 — recognition moment
Shot 05 — silence / final image
```

---

## 8. 6 Law Filter

```text
Image  — does the form carry meaning without explanation?
Sound  — does the rhythm stabilize the feeling?
Word   — does language reveal the core or cover weakness?
Motion — is movement necessary or decorative?
Matter — does texture serve truth or imitate depth?
Silence — does silence protect the meaning or hide fear?
```

## Final Rule

Do not sell the product first.
