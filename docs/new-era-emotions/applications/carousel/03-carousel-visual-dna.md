# 03 — الهوية البصرية والحركية للكروسيل

Created by: Ahmed Nabil — Nabil88 / nabil88.art

هذا الملف يخص تطبيق الكروسيل فقط.

## القانون البصري

كل مصطلح يُعرض داخل عالم ثابت، هادئ، مشحون، مع عنصر رمزي واحد يتحرك ليجسّد جوهر الشعور.

الصورة لا تشرح الحالة.
الصورة تجعل الحالة تُرى.

## الثوابت

- تكوين عمودي 4:5.
- مقاس 1080×1350.
- مساحة هادئة واسعة.
- خلفيات محايدة.
- إضاءة ناعمة أو اتجاهية محسوبة.
- نصوص قليلة وواضحة.
- عنصر بصري رمزي واحد.
- لا زحمة زخرفية.

## قانون الحركة

- الكاميرا ثابتة.
- النص ثابت.
- الخلفية ثابتة.
- العنصر الأساسي ثابت.
- عنصر واحد فقط يتحرك.
- الحركة تخدم معنى المصطلح.
- لا انتقالات ترند.

## نظام اللون

قاعدة السلسلة ثابتة.
لكل مصطلح لون نبضة واحد.

أمثلة:

- الفرطنة: برتقالي محموم أو أحمر متوتر.
- الجوع الممتلئ: ذهبي باهت.
- الانطفاء اللامع: فضي بارد.
- قلق السرعة: أزرق كهربائي.
- وحدة الضجيج: أزرق رمادي.

## معيار التماسك

- هل يبدو من نفس عائلة السلسلة؟
- هل يوجد عنصر متحرك واحد فقط؟
- هل الحركة تخدم المصطلح؟
- هل اللون يخدم الشعور؟
- هل النص واضح من أول ثانية؟
