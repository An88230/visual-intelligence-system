# RAIZ v0.1 — Showable Prototype

## Purpose

هذه أول نسخة يجب أن تكون قابلة للعرض أمام فريق أو عميل.

ليست نسخة كاملة.

ليست أداة تجريبية مبعثرة.

هي مشهد تشغيل حي يثبت أن RAIZ Creative OS يمكن أن يكون غرفة قيادة إبداعية.

## MVP Scope

### Must Have

```text
1. Futuristic spatial workspace
2. Organic Audio Orb as the center
3. Gemini Voice Mode
4. GPT Markdown Mode
5. Manual engine selection
6. Project context panel
7. Output panel in Markdown
8. Copy Markdown
9. Export Markdown
10. Local key storage in user's browser
```

### Must Not Have Yet

```text
1. No public backend
2. No database
3. No automatic editing control yet
4. No team accounts
5. No SaaS dashboard behavior
6. No complex analytics integration yet
```

---

## Engine Division

### Gemini

```text
Role: Voice Presence
Input: Voice / quick creative command
Output: Spoken response + short direction
Use: live meetings, show mode, fast interpretation
```

### GPT

```text
Role: Written Structure
Input: Text command / refined brief
Output: Markdown
Use: campaign plans, prompt architecture, VO, production plans, exportable documents
```

### RAIZ

```text
Role: Router + Memory + Interface State
Use: decides how the workspace behaves, stores project context, frames outputs visually
```

---

## Workspace Rules

```text
Every screen must be presentable.
Voice is the primary interface.
Markdown is the memory.
The workspace itself is part of the brand.
```

---

## Primary User Flow

```text
1. User opens RAIZ Creative OS.
2. User enters Gemini and GPT keys locally.
3. User chooses project mode.
4. User speaks or writes command.
5. If Gemini: RAIZ responds in voice / fast direction.
6. If GPT: RAIZ returns structured Markdown.
7. Output appears in the right panel.
8. User copies or exports Markdown.
9. Session context stays in local memory.
```

---

## Show Mode Flow

```text
1. Large Orb in center.
2. Minimal controls.
3. User speaks to RAIZ in front of team.
4. RAIZ answers with calm authority.
5. Markdown summary appears.
6. Team sees the decision forming live.
```

---

## Director Mode Flow

```text
1. Full controls visible.
2. Engine selection visible.
3. Project context editable.
4. Markdown output active.
5. Export and copy enabled.
6. Creative mode selectable.
```
