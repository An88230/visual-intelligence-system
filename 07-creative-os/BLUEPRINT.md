# BLUEPRINT — RAIZ Creative OS

## Neural Expressive UI System

**نظام تشغيل إبداعي سحابي/محلي للمخرج والمخرج البصري**

---

## 01 — الفلسفة الحاكمة / The Vision

**RAIZ Creative OS** ليس مجرد أداة لإدارة المحتوى الإعلاني أو تجميع النصوص؛ هو مساحة عصبية تفاعلية **Neural Expressive UI** تُدار بالكامل عبر التوجيه الصوتي والبصري الحي.

النظام مصمم ليعمل كمخرج يوجه "موجة" تقنية: يرى البنية الكاملة قبل الشكل، ويسمح للبيانات بالتحلل والتشكل لتعكس الصراع الإنساني داخل نظام مرئي ممتد.

---

## الثلاثية التأسيسية للنظام البصري

### 1. الفرطنة / Al-Fratna

الفهم الفطري اللحظي غير المتوقع للحالة الشعورية ونقاط التحول.

### 2. الجوع الممتلئ / Al-Jou' Al-Mumtali

إدارة الفراغ والنقص البصري ليكون فائضًا شعوريًا يبحث عنه المتلقي.

### 3. الانطفاء اللامع / Al-Intifa' Al-Lami'

السيادة والسلطة الصامتة من خلال البرودة التقنية للعالم، والدفء للإنسان فقط.

---

## 02 — بنية الواجهة التفاعلية / Neural Expressive UI

تتحرك الواجهة بعيدًا عن عناصر التحكم الجافة — الأزرار والـ Inputs التقليدية — لتتمحور حول **الفقاعة الهلامية العضوية / Organic Audio Orb** التي تعمل كمؤشر استجابة وعاطفة حي.

### الخلفية والـ DNA البصري

```text
Charcoal Dark Background: #0d0d0e
Soft Ivory Lines: #e5e5eb
Amber Human Glow: #e2b867
Cold Matrix Field: #1a1d24
Subtle Border: #222226
```

### محرك المحاكاة الحية / Live Visualization

معالجة ترددات الصوت أثناء كلام المستخدم أو رد الـ AI عبر `Web Audio API` لتشويه وتشكيل الفقاعة هندسيًا في جزء من الثانية.

الهدف ليس زينة تفاعلية.

الهدف أن يشعر المستخدم أن النظام يسمع، يتنفس، ويتفاعل بصريًا مع الموجة.

### الأمان وصفر باك-إند / Serverless Isolation

تُحفظ مفاتيح الـ APIs محليًا بالكامل عبر `localStorage` في متصفح المستخدم.

لا توجد قواعد بيانات وسيطة.

لا توجد مفاتيح مشتركة داخل المستودع.

البيانات والـ Prompts ملك المستخدم بالكامل.

## 03 — طبقة العقول الذكية / Dual-Engine API Core

يعتمد النظام على هندسة ربط مزدوجة عبر دمج محركين سحابيين لتوزيع المهام الإبداعية والمنطقية.

---

## A — محرك الصوت والهوية اللحظية / Gemini API Core

### الموديل المعتمد

```text
Gemini multimodal family
Example: gemini-2.5-flash
```

### طبيعة المهمة

- الاستماع الصوتي المباشر.
- تحليل الصوت كأمر إبداعي.
- إنتاج ردود صوتية أو نصية حسب المرحلة.
- دعم التفكير متعدد الوسائط.

### الهوية الصوتية

استدعاء خامات صوتية بشرية دقيقة مثل `Kore` عند توفر Native Audio، مع إدارة الوقفات وهندسة الصمت بأسلوب:

```text
الهدوء الثابت الذي لا يحتاج لتبرير
```

---

## B — محرك الهيكلة والمنطق الصارم / GPT API Core

### الموديل المعتمد

```text
GPT / OpenAI advanced reasoning and text models
```

### طبيعة المهمة

- إدارة الهياكل المعقدة.
- تدقيق التوافق البرمجي.
- صياغة Prompt Multi-World.
- بناء أنظمة نصية وتشغيلية دقيقة.
- تحويل الشيفرات إلى Campaign / Prompt / VO / Production Command.
