# RAIZ Creative OS

## Neural Expressive UI

RAIZ Creative OS is the future operating layer of the Visual Intelligence System.

It is not a prompt tool.

It is a creative command environment designed to connect:

```text
Voice → Thought → Visual Intelligence → AI APIs → Local Production Systems
```

---

## Core Identity

```text
Name: RAIZ Creative OS
Interface Language: Neural Expressive UI
Current Mode: Browser-only
Future Mode: Browser + Local Server + Automated Production Control
```

---

## Current Scope

The current version runs in the user's browser only.

The user provides their own API keys locally.

Supported API direction:

```text
Gemini API
GPT / OpenAI API
```

No backend is required in the first stage.

No API key is stored by the repository owner.

No server is used in the browser-only version.

---

## Why This Exists

The previous layers organize intelligence:

```text
Dictionary → System Map → Execution Layer → Tool Layer
```

RAIZ Creative OS is different.

It is the beginning of an interactive creative agent.

It should eventually control:

- visual direction
- prompt generation
- voice conversation
- creative memory
- file preparation
- automatic editing flows
- local production tools
- montage automation systems
