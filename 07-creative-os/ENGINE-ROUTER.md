# ENGINE ROUTER — RAIZ Creative OS

## Gemini + GPT Role Separation

RAIZ Creative OS does not treat AI engines as interchangeable.

Each engine has a role.

The user can choose manually.

RAIZ can later recommend the best route.

---

## Core Rule

```text
Gemini hears.
GPT writes.
RAIZ routes.
```

---

## Gemini Mode

### Role

```text
Voice Presence
Live Interpretation
Fast Creative Response
Project-aware conversation
```

### Use Gemini When

```text
- User is speaking live
- Show Mode is active
- A meeting needs fast verbal response
- The system needs to feel present
- Audio input/output matters more than document structure
- The user wants to talk, not write
```

### Output Shape

```text
Spoken response
Short visual direction
Quick creative decision
Optional short Markdown summary
```

---

## GPT Mode

### Role

```text
Markdown Structure
System Reasoning
Creative Architecture
Document Output
```

### Use GPT When

```text
- User needs a campaign structure
- User needs a prompt system
- User needs VO text
- User needs production plan
- User needs exportable Markdown
- User needs careful logic or code review
```

### Output Shape

```text
Markdown document
Structured sections
Copy-ready text
Export-ready output
Production-ready instructions
```

---

## Manual Choice

In v0.1, the user chooses:

```text
Gemini
GPT
```

No automatic routing yet.

Manual choice protects control.

---

## Future Smart Routing

Later RAIZ can suggest:

```text
This task is better for Gemini.
This task is better for GPT.

```

Future combined flow:
