# Quick Start

This repository is not a normal toolkit. It is a visual thinking system.

Start with one path only. Do not try to consume the full system in one sitting.

---

## 1. Clone the repository

```bash
git clone https://github.com/An88230/visual-intelligence-system
cd visual-intelligence-system
```

---

## 2. Read the system map first

```bash
cat SYSTEM-MAP.md
```

The map explains how the seven layers connect:

```text
Visual Codes Dictionary → Prompt Bible → Lyrical Matrix → Mother Node → Execution Layer → Tool Layer → RAIZ Creative OS
```

Read it before editing or extending the system.

---

## 3. Start with the Visual Codes Dictionary

```bash
cat 01-visual-codes-dictionary/visual-codes-dictionary.md
```

This is the master archive: **49 core visual codes** extracted from lived moments, memory, sound, advertising, language, and human observation.

Then read the standalone addition:

```bash
cat 01-visual-codes-dictionary/code-50-reinterpreting-behavior.md
```

Use the dictionary like this:

1. Pick one code.
2. Identify its emotional law.
3. Translate the law into image, sound, word, movement, or campaign direction.
4. Remove anything that does not increase the truth of the work.

Recommended starting codes:

- `07 — The Method`
- `23 — Impact Equation`
- `25 — The Full Build Chain`
- `42 — Day Zero`
- `43 — 6 Law`
- `48 — The Law of Inevitable Recognition`
- `49 — The Mask's Decay`
- `50 — Reinterpreting Behavior`

## 4. Use the Visual AI Prompt Bible

```bash
cat 02-visual-ai-prompt-bible/VISUAL_AI_PROMPT_BIBLE.md
```

Use this file when you want to convert a visual code into an AI image prompt.

Basic workflow:

```text
Subject → Emotional State → Human Structure → Visual Law → Lighting → Texture → Composition → Negative Prompt
```

Paste the final prompt into:

- Midjourney
- DALL·E
- Adobe Firefly
- Stable Diffusion
- Flux
- Any cinematic AI image workflow

Do not start with visual decoration. Start with the hidden human structure.

## 10. First practical exercise

Choose one product, person, place, or campaign.

Then answer:

```text
1. What does the audience feel but not say?
2. What visual code reveals that feeling?
3. What must be removed so the work becomes sharper?
4. What is the one image that makes recognition inevitable?
5. What sound, word, or silence should carry the impact?
```

Then build one execution:

```text
Code → Insight → Visual Direction → Prompt → Shot / Poster / Caption / VO
```
