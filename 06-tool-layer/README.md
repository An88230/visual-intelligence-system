# Tool Layer

## HTML Version

This layer turns the Visual Intelligence System into usable local tools.

The first tool is a single-file HTML generator:

```text
visual-code-generator.html
```

It works without build setup, backend, external scripts, or API keys.

Open it directly in a browser.

## Tool Philosophy

This tool does not replace the dictionary.

It only helps translate a selected code into a usable creative structure.

```text
The dictionary is the source.
The tool is the handle.
```
