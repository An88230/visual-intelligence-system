## Operating Chain

The system works best in this order:

```text
1. Read the human state.
2. Identify the visual code.
3. Select the build chain.
4. Convert the code into image, voice, or campaign structure.
5. Remove decoration.
6. Test the output against impact.
```

In practical form:

```text
Feeling → Code → Structure → Prompt / Script / Shot → Execution → Impact Test
```

---

## The Impact Test

Before accepting any output, ask:

```text
Does this explain something the viewer was already feeling?
```

If yes, the work has recognition.

If no, it is only decoration.

---

## The 6 Law Production Filter

Every output must pass through six gates:

```text
1. Image  — does the form carry meaning without explanation?
2. Sound  — does the rhythm stabilize the feeling?
3. Word   — does language reveal the core or cover weakness?
4. Motion — is movement necessary or decorative?
5. Matter — does texture serve the truth or imitate depth?
6. Silence — does silence protect the meaning or hide fear?
```

What does not pass the gates should not enter the final work.
